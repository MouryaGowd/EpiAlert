# EpiAlert: PRIVACY NOTE (draft)

**Purpose.** Alert nearby medical volunteers to an incident.

| Data | Who | Retention | Visible to |
|---|---|---|---|
| Phone number (auth) | all users | until account deletion | server only |
| Poster location | poster, once at post time | with incident, 24 h | alerted responders (incident location) |
| Blurred photo | poster | 24 h | poster, alerted responders |
| Responder live location | on-duty responders | overwritten while on duty; cleared when off duty | server only |
| Proof documents | responders | deleted after a decision (retention chosen: delete on decision) | admin reviewers |
| Audit log | none personal | indefinite, no uids/names/photos, coarse area only | server only |

Ordinary users' location is never stored. EpiAlert is not a medical device and not an emergency service.

**DPDP Act 2023.** Commentary sources report that the DPDP Rules, 2025 were notified in November 2025 with staged commencement, core obligations about 18 months later (around May 2027). Not yet checked against the Gazette; do not state exact dates until confirmed. See DECISIONS.

**Good Samaritan law.** Not yet researched. No claim of legal immunity will be made.
